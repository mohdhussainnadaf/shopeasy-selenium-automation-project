# ShopEasy Selenium Automation Testing Project

This project automates test cases for the ShopEasy demo e-commerce website using Selenium WebDriver and Pytest.

## Website Under Test

https://mohdhussainnadaf.github.io/my-first-project-shop-easy/

## Tools Used

- Python
- Selenium WebDriver
- Pytest
- WebDriver Manager
- Pytest HTML Report

## Test Cases Automated

- Valid login
- Invalid login
- Product search
- Add product to cart
- Remove product from cart
- Checkout with valid details
